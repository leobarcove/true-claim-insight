Open gap

Change something shows no options and does not allow typing

Found 28 August 2026 · claimant web chat review · all gaps · markdown record

What goes wrong

  • Transcript label: Asked to change something (callback false).
  • Bot reply: Which detail would you like to change?
  • Composer still shows Confirm and submit / Change something only.
  • Tapping again repeats the same two bubbles.

Cause

The gateway already builds a synthetic choice step __edit-menu with one option per answered field. Web chat currentStep is taken from the Case review confirm step, not from that menu, so the PWA never renders the choices or a text box.

Done when

After Change something, the claimant can pick a field from a list, or type which detail to change. The review buttons must not stay as the only control.
